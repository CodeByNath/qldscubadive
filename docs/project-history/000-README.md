# Project History

Project History records completed architectural milestones for the QSD Platform. It is separate from the [Code Map](../code-map/000-README.md), which always describes the current implementation.

## Rules

- A completed history document is immutable; later work gets a new, sequentially numbered document (`001-…`, `002-…`).
- Create a history document only for a major implementation, migration, refactor, repair, or architectural change, and only after asking the project owner.
- Keep each milestone focused, roughly 300–1,000 words.
- Routine maintenance, minor fixes, and formatting do not get milestones.

## Origin

The platform core (Service and Category Stations, Platform Identifier Station, lifecycle engine, drawer kit, Station Manager, and Admin Station) was extracted from the CompuZign platform in September 2026. The extraction itself is recorded in the Git history of this repository; CompuZign's own milestone records were not carried over.
