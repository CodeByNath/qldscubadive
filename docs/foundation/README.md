# Foundation

Foundation holds durable repository-wide operating rules for QSD within each document's stated scope. It does not replace QSD architecture, accepted contracts, Code Maps, Project History, or verified source.

## Subjects

- [Repository governance](repository-governance.md)

## Authority and scope

Repository/product architecture remains in QSD architecture documents, accepted contracts, Code Maps as navigation, and verified implementation. Foundation may define durable repository-operability rules such as branch capacity, authored-file limits, and Code Map maintenance when separately authorised.

The `Project-work-instructions` branch coordinates active work only and never becomes product architecture authority.

## Change rule

Change Foundation rules only through authorised work. If a proposed operating rule changes product architecture, record the architecture decision in the appropriate QSD authority first.

## Maintenance

Reviewers verify that Foundation remains within its operating scope and does not duplicate or conflict with QSD architecture or verified implementation.
