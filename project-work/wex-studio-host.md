## Reviewer decision — 17 October 2026, Phase 1I candidate `5d90ba87da0893c3acee4529ed3dffc753eac86e`

**Verdict: Stop — architectural risk.** Independently inspected pushed staging source against WEX ADR 0025. QSD `StudioStagingPointer::fetchAndValidatePointer()` accepts `previous` only as null or a release-ID string, but ADR 0025 mandates `previous: {sequence,releaseId,manifestDigest}` after sequence 1. Thus the first real pointer advance will be rejected. The code also writes the new durable accepted selection with `update_option` **before** `StudioReleaseLock::verifiedRelease()` checks the candidate manifest; on invalid/unreachable manifest it may strand selection on an unverified release, contrary to last-verified fallback. `readState()` checks types but not trusted origin, manifest path, digest format, contract or releaseId, so durable-state corruption of valid types is not safely rejected. Reported tests/CI success and server deployment do not prove live activation; `WP_ENVIRONMENT_TYPE=staging` and authenticated `/studio/` fetch remain unverified.

**Bounded correction package (QSD only):** (1) Parse/validate the actual ADR 0025 `previous` object (including sequence and digest); implement skipped-sequence handling consistent with the accepted consumer security contract, without ignoring replay/chain protection. (2) Accept/persist a new highest sequence only after the manifest passes the existing full raw-digest and inventory verification; retain an independently verified last-known-good pin and use it on pointer/manifest outage or tamper. (3) Fully validate stored state, avoid trusting arbitrary durable URLs, and add deterministic tests covering real sequence-2 advance, forged previous, manifest mismatch/outage after pointer advance, restart/replay, and safe fallback. Preserve production fixed pin, staging-only gate, Logo/auth, existing scope and four-branch capacity. (4) Run required QSD checks and deploy staging only; record exact pushed SHA, CI and honest real-runtime evidence, including environment gate. Stop for independent review.
