## Builder — Profile-ID logo data plug, zero-change proof (2026-10-13)

**Resolution: the existing contract already satisfies this assignment; no production mapping was missing.** `AccountSchema::NODE_ORDER` includes `PlatformIdentifierPolicy::ACCOUNT_PROFILE` (prefix `QSDASTP`), the exact Profile platform ID — a fixed singleton (`account_profile:root`), never a catalogue entry. `AccountController::projection()` (backing `GET /qsd/v1/admin/account`, `permission_callback: requireAdmin`) already returns `nodes.profile.platform_id` and `brand.logo_url` (resolved via `AccountMedia::url()` from the same `logo_media_id`) **in the same response**. That is the complete "Profile ID → logo data" plug: one admin-authenticated request, both pieces of data, no DOM/CSS/component involved, no new route.
